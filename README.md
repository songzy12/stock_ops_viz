# Stock OP Visualizer

A lightweight Python tool to visualize stock price trends and highlight specific operation dates (buy/sell/milestones).

## Features

- **Historical Data Retrieval**: Fetch daily stock prices for any ticker (e.g., `IBM`, `AAPL`) using the Alpha Vantage API.
- **Trend Visualization**: Generate clean, interactive time-series plots using Matplotlib.
- **Operation Highlighting**: Overlay specific dates with prominent markers to visualize the impact of operations or events.

## Tech Stack

- **Language**: Python 3.x
- **Libraries**:
  - `requests`: For communicating with stock APIs.
  - `pandas`: For data manipulation.
  - `matplotlib`: For high-quality plotting.

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/stock_op_visualizer.git
   cd stock_op_visualizer
   ```

2. Install dependencies:
   ```bash
   pip install yfinance pandas matplotlib
   ```

## Usage

The tool is split into two components for better flexibility.

### 1. Fetching Data
Use [fetcher.py](fetcher.py) to download historical stock data and store it locally as a CSV.

```bash
python fetcher.py --ticker GOOG --apikey YOUR_API_KEY
```

- `--ticker`: The stock symbol.
- `--apikey`: (Optional) Your Alpha Vantage API key. If not provided, it will check the `ALPHA_VANTAGE_API_KEY` environment variable.

### 2. Visualizing and Highlighting
Use [visualizer.py](visualizer.py) to read the local CSV and generate a chart with highlighted operation dates.

```bash
python visualizer.py --input data/GOOG_data.csv --ops ops.txt --start 2022-01-01
```

- `--input`: Path to the CSV file generated by the fetcher.
- `--ops`: Path to a `.txt` file containing dates (one per line) OR a comma-separated list of dates.
- `--start`: The start date for the visualization (default: `2022-01-01`).

The chart will be saved as a PNG file in the same directory as the input CSV.
