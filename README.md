# Stock OP Visualizer

A lightweight Python tool to visualize stock price trends and highlight specific operation dates (buy/sell/milestones).

## Features

- **Historical Data Retrieval**: Fetch weekly stock prices for any ticker (e.g., `IBM`, `AAPL`) using the Alpha Vantage API.
- **Trend Visualization**: Generate a JPG and an interactive HTML time-series chart.
- **Operation Highlighting**: Overlay specific dates with prominent markers to visualize the impact of operations or events.

## Tech Stack

- **Language**: Python 3.x
- **Libraries**:
  - `requests`: For communicating with stock APIs.
  - `pandas`: For data manipulation.
  - `matplotlib`: For high-quality plotting.
  - `plotly`: For interactive HTML charts.

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/stock_op_visualizer.git
   cd stock_op_visualizer
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

The tool is split into two components for better flexibility.

### 1. Fetching Data
Use [fetcher.py](fetcher.py) to download historical stock data and store it locally as a CSV.

```bash
python fetcher.py --ticker GOOG --apikey YOUR_API_KEY
```

- `--ticker`: The stock symbol.
- `--apikey`: (Optional) Your Alpha Vantage API key. If not provided, it will check the `ALPHA_VANTAGE_API_KEY` environment variable.

### 2. Visualizing and Highlighting
Use [visualizer.py](visualizer.py) to read the local CSV and generate a chart with highlighted operation dates.

```bash
python visualizer.py --input data/GOOG_data.csv --ops input/ops.txt --start 2022-01-01
```

- `--input`: Path to the CSV file generated by the fetcher.
- `--ops`: Path to a `.txt` file containing dates (one per line) OR a comma-separated list of dates.
- `--start`: The start date for the JPG (default: `2019-07-15`); it does not limit the HTML chart.
- `--outdir`: Directory for the generated charts (default: `output/`).

Both JPG and HTML charts are saved in the output directory. The HTML chart includes all CSV data and is saved as `GOOG_data_chart.html` (for the example above); subsequent runs for the same CSV overwrite it. It opens showing the last eight years, or all available data if there is less history. Choose **10 years**, **7 years**, **4 years**, **3 years**, or **1 year** above the chart. The year buttons look backward from the current right edge of the chart. Move the cursor over the chart to see a vertical guide, date, and closing price, or use the toolbar to zoom or pan. The HTML works offline.

The fetcher supplies weekly prices, so the chart shows the dates available in the CSV rather than every trading day. Operation markers use the nearest available date within one week and change from light red to dark red when the vertical guide reaches them, without displaying operation text. As in the JPG chart, closing prices before July 22, 2022 are divided by 20.
